# Changelog

## 0.3.3 — extended glitch animation

- Replaced the 220 ms button pulse with a one-second stepped digital distortion, featuring displaced horizontal bands, stronger chromatic separation and a final fade.
- Underlying actions remain immediate; existing keyboard, touch, mouse and reduced-motion handling is unchanged.
- Updated offline cache; dictionary, puzzles and application logic unchanged.

## 0.3.2 — Glitchout interaction feedback

- Added a 220 ms cyan/magenta RGB-split effect on button and expandable-card activation, including dynamically generated controls.
- Feedback works through mouse, touch and keyboard click activation without delaying the underlying action; disabled controls and reduced-motion preferences are respected.
- Updated offline cache version. No changes to dictionary entries, puzzle data, code runner or saved progress keys.

## 0.3.1 — official organisation logo

- Replaced the generic code-bracket emblem with the supplied Glitchout-Co logo, resized for the header without redesigning the original artwork.
- Added restrained cyan and magenta header accents; retained the Pocket Lab app icon and existing interface.
- Cached the local logo for offline use. No changes to learning content, application logic or local progress storage.

## 0.3 — Glitchout-Co visual refresh

- Charcoal and electric-blue visual identity with violet accents and an original code-bracket brand mark.
- Responsive header, sticky section navigation, improved search and puzzle filters, and refined code panels.
- System, dark and light theme controls with local preference storage.
- Learning overview, puzzle progress bar and difficulty labels.
- Preserved all dictionary entries, puzzle content, reference versions, and existing bookmark/progress storage keys.
- Updated the manifest colours and offline cache version.
